# CT Deformation Analysis Pipeline

##  Project Overview
Accurate anatomical alignment and deformation tracking are critical in **Robust Radiotherapy Planning**. Patient anatomy changes between treatment fractions due to factors like weight fluctuations, organ motion, and tumor shrinkage. 

This repository provides a complete, reproducible, and automated pipeline to calculate, process, and visualize inter-fractional displacement and deformation fields across multi-patient datasets (using Fraction 1 as the reference/fixed scan against all subsequent fractions).

---

##  Repository Structure & File Breakdown

### 1. `calculate_deformation.py`
* **Purpose:** The core computational script designed for **Batch Cohort Processing**. It utilizes **SimpleITK** and `glob` to automatically iterate through all patient directories, load NIfTI-formatted CT scans (`.nii.gz`), perform demons registration, compute dense spatial displacement fields, and export the results.
* **Code Logic:** 
  - Dynamically detects all patient folders matching `Patient_*`.
  - Reads the fixed reference image (`Fraction 1`) and loops through all subsequent fractions dynamically.
  - Executes `DemonsRegistrationFilter` to map voxel-level transformations and saves the deformation field vectors into structured output directories.

### 2. `visualize_result.py`
* **Purpose:** Interactive 3D quality assurance and validation script using **napari**.
* **Code Logic:**
  - Loads the fixed CT array (`Fraction 1`), moving CT array (`Fraction 2`), and the computed deformation field file (`def_field_frac1_to_frac2.nii.gz`).
  - Initializes a multi-layered `napari` viewer.
  - Overlays the anatomical scans with interactive vector layers (`viewer.add_vectors`) so researchers can inspect tissue shifts and displacement directions in 3D across axial, coronal, and sagittal planes.

### 3. `run_deformation.slurm`
* **Purpose:** High-Performance Computing (HPC) batch script optimized for cluster environments (such as the Athena cluster).
* **Code Logic:**
  - Requests necessary computational resources (CPU/GPU nodes, memory, runtime).
  - Activates the designated virtual environment (`myenv`).
  - Executes `calculate_deformation.py` in a headless batch mode to process heavy volumetric medical data efficiently across the cohort.

### 4. `results/`
* **Directory Structure:** Stores the processed outputs generated by the pipeline.
* **Outputs:** Contains subfolders per patient (e.g., `Patient_01/deformation_fields/`) housing the calculated `.nii.gz` deformation field matrices mapping voxel-by-voxel positional shifts.

##  Future Goals & Next Steps
* **Deep Learning Integration:** Feed calculated displacement fields and pre-processed temporal CT data into deep learning architectures (such as Flow Matching or neural network models) to predict future anatomical deformations before treatment delivery.
* **Clinical Metrics Automation:** Automate the calculation of dosimetric impact and target volume shifts (CTV/PTV margins) directly from the deformation outputs.
